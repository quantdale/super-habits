## Determinism engineering (design D15.2)

| Source of drift               | Control                                                                                             |
| ----------------------------- | --------------------------------------------------------------------------------------------------- |
| Stale/stale-credential build  | `npm run build:e2e` only; leak guard must report 0 hosts                                            |
| State leakage between cases   | `resetAll` (OPFS + AsyncStorage + SW caches) + `seedFixture` per snapshot                           |
| Clock/day labels/greeting     | `installClock(page, '2026-10-13T19:30:00')` before the first render                                 |
| Font fallback                 | `document.fonts.ready` + 150 ms bounded settle (assertion precedes it)                              |
| Entrance springs/cross-fades  | `reducedMotion: 'reduce'` emulated **and** `animations: 'disabled'` at capture                      |
| Host DPI                      | `deviceScaleFactor: 1` in the project                                                               |
| Network                       | Local DB harness only; no external requests or images                                               |
| **Overlay background scroll** | Every scrollable element is reset to a known offset before capture (found during the two-run proof) |
| Masking                       | None — the fixed clock makes the date heading and greeting deterministic, so no region is masked    |

## Two-run stability proof

| Run   | Command                                              | Result                   |
| ----- | ---------------------------------------------------- | ------------------------ |
| Run 1 | `E2E_PORT=8089 npx playwright test --project=visual` | **30 passed / 0 failed** |
| Run 2 | `E2E_PORT=8090 npx playwright test --project=visual` | **30 passed / 0 failed** |

Baseline hash before Run 1 = after Run 2 =
`0676368d1a1c2bd45642db038406209a3195ac711c86a71248aad41b0f64bc40`
(`sha256sum e2e/__screenshots__/*.png | sha256sum`). Neither run rewrote a
baseline, and neither produced a diff artifact.

**A real nondeterminism was found and fixed during this proof.** The first Run 2
attempt failed on `achievements-390-light` (15,038 px, ratio 0.05). The diff
showed the overlay's _background_ page at a different scroll offset: Playwright's
click auto-scrolls the trigger into view, and the app's page scroll is an RN Web
`ScrollView` (an inner `overflow: auto` div), so `window.scrollTo` did not
normalise it. `capture()` now resets every scrollable element before capturing.
This was fixed at the source of the drift — no pixel tolerance was granted
(`maxDiffPixels: 0` throughout).

## Negative sensitivity proof

Perturbed `features/overview/OverviewScreen.tsx` with an isolated
`marginTop: 40` on the Today greeting, rebuilt hermetically, and ran the suite:

- **18 of 30 snapshots failed** with diff artifacts (every snapshot whose
  viewport includes the Today header or sits behind the hub/overlay that renders
  it).
- Restored the file (`git diff --stat` clean), rebuilt, and re-ran:
  **30 passed / 0 failed**.

So a green result is evidence, not an assumption.

## Baseline update process

1. `npm run visual:update` — local only, never CI.
2. Open previous / proposed / diff images side by side.
3. Justify the intentional design change with its source revision.
4. Record it in `golden-manifest.md`.
5. Reject unexplained shifts; no threshold is ever widened to pass.

## Not covered / limitations

- Baselines are Chromium-only, matching the repository's supported capture
  environment (`scripts/serve-e2e.js`). A Linux-vs-Windows renderer difference
  is a documented exclusion, not something the thresholds absorb; CI runs the
  same pinned browser.
- The suite asserts appearance only. Functional semantics stay with the existing
  unit/integration/journey specs; no functional test was replaced or weakened.
- `visual:update` must be run deliberately by a reviewer; CI has no path to
  write a baseline.
